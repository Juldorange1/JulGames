Comment lire les scores

Au-dessus de chaque colonne jouable, le solveur affiche le resultat exact de ce coup avec un jeu parfait des deux cotes : un nombre vert = victoire dans ce nombre de coups pour le joueur qui vient de jouer, un nombre rouge = defaite dans ce nombre de coups, = = partie nulle. Plus le nombre de coups avant victoire est petit, plus le coup est fort.

Le solveur est compile en WebAssembly (environ 15x plus rapide qu'un calcul JavaScript pur) et tourne dans un thread separe (Web Worker) : il ne bloque jamais le jeu, vous pouvez toujours jouer, annuler ou relancer une partie pendant qu'il calcule. Les ouvertures les plus frequentes sont precalculees dans un livre d'ouverture et s'affichent instantanement ; les positions plus rares se resolvent en direct, generalement en quelques secondes.
