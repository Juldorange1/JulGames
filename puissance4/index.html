Comment lire les scores

Au-dessus de chaque colonne jouable, le solveur affiche le resultat exact de ce coup avec un jeu parfait des deux cotes : un nombre vert = victoire dans ce nombre de coups pour le joueur qui vient de jouer, un nombre rouge = defaite dans ce nombre de coups, = = partie nulle. Plus le nombre de coups avant victoire est petit, plus le coup est fort.

Le solveur est le moteur de reference de Pascal Pons (Connect 4 Game Solver), compile en WebAssembly, avec son livre d'ouverture precalcule complet (33 Mo, charge une fois au demarrage). Resultat : chaque position, y compris le plateau totalement vide, se resout en quelques millisecondes.
