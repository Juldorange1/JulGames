Éditeur

Clic gauche : poser · Clic droit : retirer · Glisser : orbiter la caméra · molette : zoom · ZQSD/WASD + Q/E : déplacer la vue · R : orienter le PROCHAIN bloc à poser (vent, pad de vitesse, téléporteur) — le bouton "Orientation" apparaît alors ci-dessous et une flèche blanche montre le sens sur l'aperçu et une fois posé · P : régler sa puissance (vent)
Pour changer le sens d'un bloc DÉJÀ posé : passe en outil Sélectionner, clique dessus, puis R.
Les marqueurs (translucides) ne bloquent pas le joueur. Porte de phase se pose par paire : les deux premiers marqueurs du même type se lient, les deux suivants forment une autre paire, etc.

"Quart de bloc" : les plateformes/pics posés ensuite occupent un quart de la surface au sol d'une cellule (moitié en largeur, moitié en profondeur), pour un placement bien plus précis — sans effet sur les marqueurs (vent, checkpoint...), toujours posés en taille normale.

Clic sur un bloc : le sélectionner · Une fois sélectionné, tout clic (y compris sur lui-même ou sur un point déjà posé) ajoute un point de passage juste à côté de la face cliquée — viser le dessus pose un point au-dessus, pour le faire monter puis redescendre · Clic droit : retirer le dernier point · Échap : désélectionner.
Un bloc avec des points de passage s'y déplace en boucle, indéfiniment, à la vitesse réglée ci-dessous.
Bloc vent/vitesse/téléporteur sélectionné : le bouton "Orientation" (ou la touche R) change son sens — la flèche blanche sur le bloc tourne avec.
